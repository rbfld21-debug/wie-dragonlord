The browser SMAF instrument renderer links the WildMIDI library (LGPL v3 or later).
Its source is available at https://github.com/Mindwerks/wildmidi/tree/58b66625a072f017313f83c9a1a1c050188ec069 .
The build fetches that exact revision and includes its LGPL license in the app's web assets.
The small `smaf-render.c` bridge is part of this repository.
